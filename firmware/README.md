# Firmware Releases

Ready-to-flash firmware files are distributed through the repository's
[GitHub Releases](https://github.com/hiby-modding/hiby-mods/releases).

The `firmware/` directory does not contain compiled `.upt` packages. Keeping
release artifacts outside the main source tree avoids duplicating large binary
files in the repository.

Before installing modified firmware:

- Confirm that the release supports your exact HiBy device model.
- Read the release notes and installation instructions.
- Keep a compatible copy of the official stock firmware available for recovery.
- Understand that installing modified firmware is done at your own risk.

Do not submit complete stock or modified firmware packages directly to this
directory. Firmware release artifacts should be attached to the appropriate
GitHub Release instead.
